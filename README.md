# Tilky Showcase

Eleven short example levels for [Tilky Engine](https://github.com/BenBerke/Tilky-Engine), each introducing one feature, with fully commented Lua scripts.

| Level | Shows |
|---|---|
| 01 First Steps | Walking, running, stairs, jumping, a springboard |
| 02 Doors and Keys | Sector doors, a locked door and its key |
| 03 Moving Floors | A lift and a button that raises a step |
| 04 Lighting | Flickering, switchable and colour-changing sector lights |
| 05 Collectibles | Tagged coins, a HUD counter, a gate |
| 06 Flipbook Animation | Animated sprites and flipbook frame events |
| 07 Sound | 3D sound, a radio, sound pads |
| 08 Open Sky | Skybox and time of day |
| 09 Target Practice | Mouse input and raycasts |
| 10 Room Over Room | One sector with two stacked storeys |
| 11 3D Models | Model components (.glb) |

## Install

1. Download `Tilky_Showcase-<version>.zip` from [Releases](../../releases).
2. Extract it into `Documents/Tilky Engine/Projects/`, so you get `Projects/Tilky Showcase/project.tilky`.
3. Open the project from the Tilky launcher, then double-click `Assets/New Assets/01 First Steps/Showcase 01 - First Steps` and press Play.

`Assets/New Assets/README_.txt` explains the controls and how to export a game.

Requires an engine version newer than 1.1.0 (3D models, flipbooks, skyboxes and the `public` script fields are used throughout).
